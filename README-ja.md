# Ukulele Chord Explorer

ウクレレのコードボイシングを、指板全体（0〜15フレット）にわたって探索できる単一HTMLファイルのWebアプリです。ビルド不要で、開放ポジションの基本形からハイポジションの「Ultra」ボイシングまで確認できます。

**公開URL:** https://tokudiro.github.io/ukulele-chord-explorer/

[English README is here](README.md)

## 機能

- **全ボイシングの網羅探索**: ルート音とコードタイプを指定すると、0〜15フレットの範囲で押さえられる運指をすべて生成します。教則本に載っている定番の数パターンだけではありません。
- **ポジション範囲フィルタ**: Low(0-4F) / Mid(5-8F) / High(9-11F) / Ultra(12F+)で絞り込めます。
- **フォーカスビュー**: 大きめのコードダイアグラムをPrev/Nextで切り替えながら再生できます。縦向き・横向きの表示切替にも対応します。
- **パノラマ指板マップ**: 指板全体のコード構成音を一覧できます。音名表示と度数表示を切り替えられます。
- **全ボイシング一覧**: マッチする運指をグリッドで一覧し、タップして選択できます。
- **再生機能**: Web Audio APIでストローク音を再生します。音色はUkulele / Soft / Buzzy / Retroから選べます。
- **クイック検索**: `Am7`や`C#m`のようにコード名を入力すると、該当のコードへ直接移動します。
- **設定パネル（歯車アイコン）**: High-G / Low-Gチューニング切替、レフティ（左利き）モード、アクセントカラー、ライト/ダークテーマをまとめて変更できます。
- 対応コードタイプは14種類: Maj, m, 7, M7, m7, m7b5, dim7, 6, m6, sus4, 7sus4, add9, 9, aug

## 使い方

依存ライブラリのインストールやビルド作業は不要です。単一のHTMLファイルとして動作します。

- [`index.html`](index.html)をブラウザで直接開く
- または[公開ページ](https://tokudiro.github.io/ukulele-chord-explorer/)にアクセスする

## 技術構成

- HTML / CSS / JavaScriptのみで構成された単一ファイルです。
- CSSフレームワークには[Tailwind CSS](https://tailwindcss.com/)のPlay CDN版を使用しています（JIT、任意値クラス、クラスベースのダークモードに対応）。
- コード再生にはWeb Audio APIを使用しています。
- フレームワーク・バンドラー・パッケージマネージャーへの依存はありません。
